# 执行模式约束（通用模板）

## 执行模式（强制）

**本技能采用 Agent 自主执行模式**：

### 主 agent 禁止行为
- ❌ **禁止手动操作**：主 agent 不得直接调用 bash/grep/read 等工具执行本技能的核心功能
- ❌ **禁止中途介入**：主 agent 不得在子 agent 执行过程中手动干预
- ❌ **禁止自行解析**：主 agent 不得自行解析日志、代码或数据

### 子 agent 职责
- ✅ **自主执行完整流程**：按照技能定义的阶段/步骤自主完成
- ✅ **并行发起查询**：首轮必须并行发出多个查询，不串行等待
- ✅ **解析并定位**：自主解析结果并定位根因/问题点
- ✅ **输出结构化结论**：按技能要求的格式输出完整结论

### 调用方式
```
用户：用 <skill-name> 查一下 xxx
主 agent：调用 Skill(<skill-name>, args={...})
子 agent：自主执行 → 输出结论
主 agent：将结论返回给用户
```

### 例外情况
仅在以下情况允许主 agent 手动操作：
1. 技能明确标注为"参考模式"（而非 Agent 模式）
2. 用户明确要求主 agent 手动执行
3. 子 agent 执行失败且无法恢复

---

**注意**：此模板适用于需要自主执行的技能（如 cwork-log, cwork-bug, cwork-data 等）。
对于纯知识型技能（如 cwork-tech-writer, cwork-wuxia-writer），不需要此约束。
