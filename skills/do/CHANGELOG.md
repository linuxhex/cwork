# cwork-do 变更日志

## [2026-11-09] 高门槛自动改进机制

**触发**：用户要求提高改进门槛，自动执行不需人工介入
**改动**：技能改进自检改为三层检查（门槛检查→自动执行→验证同步记录）
**影响**：只有绝对确定的改进才会自动执行，推测性改进记入 USAGE_NOTES

## [2026-11-09] 新增任务结束自检

**触发**：借鉴 Hermes Agent 自改进机制
**改动**：收敛后加「技能改进自检」章节（含迭代模式分析），任务结束自动输出改进提议
**影响**：每次 do 任务结束会提议技能改进

## [2026-11-06] 实测证据溯源硬约束

**触发**：实战发现收敛报告编造证据、本地运行冒充部署态
**改动**：加实测证据溯源硬约束（工具来源标注+数字须真实返回+幻觉判✗）
**影响**：收敛评估更严格，禁止编造证据

## [2026-11-01] 迭代保底放宽

**触发**：5 轮保底太紧，复杂任务常不够
**改动**：迭代保底从 5 轮放宽到 10 轮
**影响**：复杂任务有更多迭代空间

## [2026-10-30] 目标驱动改造

**触发**：固定线性 5 阶段不够灵活
**改动**：改造为目标驱动+迭代收敛工作流，阶段 1 固化验收标准作锚点
**影响**：工作流更灵活，以目标达成为准

## [2026-09-10] 新增自主工作流技能

**触发**：需要串联 implement/bug → deploy → test → commit 完整流程
**改动**：新增 cwork-do 技能，grill-me 追问确认工作目标
**影响**：复杂目标可以端到端自动完成
