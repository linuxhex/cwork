## 检索规则

遇到新问题时：
1. 提取关键字（技能名 + 现象词）
2. 在本文件中搜索相似任务
3. 如果命中：
   - 检查「踩坑」和「关键决策」是否适用
   - 适用 → 直接参考，避免重复踩坑
   - 不适用 → 继续当前任务
4. 如果未命中：
   - 完成任务后提取新模式
   - 提议加入本文件
