# cwork 模式库

> 从实战中提取的可复用模式/反模式。每次任务结束自检时查阅。
> 参考 `common/learning-loop.md` 的完整规范。

---

## 反模式（HARD GATE 来源）

### [P001] 空壳输出
- **现象**：查询/分析结果只有一句话
- **根因**：阶段 3 没有硬门禁
- **解法**：各技能加必填字段自检
- **关联技能**：log/data/config/graf/deploy
- **来源**：USAGE_NOTES 2026-11-05

### [P002] 盲试选择器
- **现象**：测试时反复换选择器尝试
- **根因**：没有先 snapshot 看真实 DOM
- **解法**：known-pits 强制先 snapshot 再写选择器
- **关联技能**：test
- **来源**：USAGE_NOTES 2026-11-02

### [P003] 并发更新数据不一致
- **现象**：多线程/多实例同时更新同一数据，结果不一致
- **根因**：未加锁或锁粒度不对
- **解法**：加分布式锁或数据库行锁
- **关联技能**：bug/implement
- **来源**：待补充

### [P004] 编造实测证据
- **现象**：收敛报告对不存在的桩编成功率，标「实测 ✓」
- **根因**：AI 幻觉 + 无溯源硬约束
- **解法**：实测证据溯源硬约束（工具来源标注+数字须真实返回+幻觉判✗）
- **关联技能**：do
- **来源**：USAGE_NOTES 2026-11-05

### [P005] 本地运行冒充部署态
- **现象**：把本地运行结果当成部署态证据
- **根因**：未区分本地运行 vs 部署环境
- **解法**：部署态如实字段 + 反模式清单
- **关联技能**：do
- **来源**：USAGE_NOTES 2026-11-05

### [P006] 凑数断言假通过
- **现象**：测试通过但实际没验证关键逻辑
- **根因**：断言不可证伪 / 凑数等待 / 凑数断言盖住完整失败证据链
- **解法**：「断言必须可证伪」比「断言存在」更重要
- **关联技能**：test
- **来源**：USAGE_NOTES 经验沉淀

### [P007] 换皮重试浪费轮次
- **现象**：判定 paimon/Trino 后仍去「探模板/试 count/换 tool」
- **根因**：无硬门禁拦截
- **解法**：命中即 MCP 全 7 tool 禁用，一次判定不翻案
- **关联技能**：data
- **来源**：USAGE_NOTES 2026-11-05

## 可复用模式

### [M001] 多服务早期识别
- **触发**：需求分析阶段发现跨服务调用
- **动作**：立即切换多服务模式，为每个服务建独立文档
- **关联技能**：implement
- **来源**：implement SKILL.md

### [M002] 收敛双证据
- **触发**：cwork-do 每轮迭代结束
- **动作**：同时收集实测证据 + 理论推演
- **关联技能**：do/implement/bug
- **来源**：do SKILL.md

### [M003] 任务结束自检
- **触发**：implement/bug/do 任务完成时
- **动作**：执行 4 项自检（已知坑/重复动作/文档偏差/新反模式），输出改进提议
- **关联技能**：implement/bug/do
- **来源**：learning-loop.md（2026-11-09 新增）

### [M004] 登录判据确定性 URL
- **触发**：测试登录场景
- **动作**：必须 waitForUrl/assertUrl（URL 离开登录页），禁止以 aiAssert/按钮状态作判据
- **关联技能**：test
- **来源**：USAGE_NOTES 经验沉淀

### [M005] 异步渲染轮询可见性
- **触发**：测试异步渲染组件（element-ui nextTick 面板等）
- **动作**：禁止同步 count，必须轮询可见性
- **关联技能**：test
- **来源**：USAGE_NOTES 经验沉淀

### [M006] 执行器硬超时
- **触发**：ego 原生等待（waitForElement/click/fill）
- **动作**：执行器必须 withHardCap，防「条件永不满足」时永不 resolve
- **关联技能**：test
- **来源**：USAGE_NOTES 经验沉淀

### [M007] 源仓库双写
- **触发**：执行器/脚本改动
- **动作**：必须回源仓库双写（`$CWORK_HOME/skills/`），禁止只 patch 安装副本
- **关联技能**：test/deploy/所有技能
- **来源**：USAGE_NOTES 经验沉淀

### [M008] 时间戳命令驱动
- **触发**：查日志需要时间范围
- **动作**：时间戳禁止心算，命令驱动；搜索关键字单号优先
- **关联技能**：log
- **来源**：USAGE_NOTES 经验沉淀

### [M009] 跨 catalog 分别查
- **触发**：Doris 跨 catalog JOIN 大表
- **动作**：分别查各 catalog 取回小结果集本地关联，禁止跨 catalog JOIN（易 OOM）
- **关联技能**：data
- **来源**：USAGE_NOTES 经验沉淀

### [M010] Jenkins CSRF 防护
- **触发**：Jenkins POST 请求
- **动作**：必须 crumb+cookie jar（CSRF），触发失败/轮询超时一律报错 return 1
- **关联技能**：deploy
- **来源**：USAGE_NOTES 经验沉淀

## 模式匹配规则

遇到新问题时：
1. 提取关键字（技能名 + 现象词）
2. 在本文件中搜索相似模式
3. 如果命中：
   - 检查解法是否适用
   - 适用 → 直接应用，记入本次任务日志
   - 不适用 → 创建新模式或修正现有模式
4. 如果未命中：
   - 解决问题后提取新模式
   - 提议加入本文件
